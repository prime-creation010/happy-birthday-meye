ANUSREE — BIRTHDAY WEBSITE
===========================

A responsive birthday website created by Prime Creations.

HOW TO VIEW
1. Extract the ZIP folder.
2. Open index.html in a browser.
3. Keep the assets folder beside index.html and style.css.
4. The "The people behind this" link opens brand.html.

FILES
- index.html       Main birthday website
- brand.html       Prime Creations brand/about page
- style.css        Responsive visual styling
- script.js        Gallery lightbox and small interactions
- assets/          Logo and Anusree's supplied photographs

CUSTOMISATION
- Edit the text directly in index.html.
- Replace the photos in assets while keeping the same filenames, or update the image paths in index.html.
- The page uses Google Fonts when internet access is available; fallback fonts are included.
- No backend, account, or database is required.

Made with care by Prime Creations.
